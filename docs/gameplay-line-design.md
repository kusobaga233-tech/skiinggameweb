# 引导线设计思路

引导线的核心是给赛道建立一条推荐滑行路线，让角色在没有明显操作时自然靠近这条路线，减少玩家因为小幅偏航而错过旗门的情况。

推荐路线由旗门中心点串联形成。角色不会被直接拉到线上，而是通过轻微调整前进朝向，逐渐向推荐路线靠近，这样手感会更像“顺着雪道滑”，而不是被系统横向拖拽。

玩家输入仍然优先。玩家向左或向右倾斜时，角色可以主动偏离推荐线，用来切内线、调整入弯位置或避开障碍。玩家松开输入后，角色再缓慢回到推荐路线附近。

在大弯区域，引导线只做弱提示和轻微修正，不能强行接管过弯。大弯仍然需要玩家主动控制入弯位置和转向节奏，否则会削弱玩法。

总体目标是让直道和小修正更舒服，让大弯保留操作挑战。
