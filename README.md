# Skiiing Web

Browser-based skiing MVP with camera/body-sensing controls.

## Live Demo

GitHub Pages:

https://kusobaga233-tech.github.io/skiinggameweb/

## Local Development

```powershell
cd D:\CODEX-PROJ\Skiing\web
npm install
npm run dev
```

Open:

http://localhost:5173/

## Build

```powershell
cd D:\CODEX-PROJ\Skiing\web
npm run build
```
